개인정보처리방침

작성일: 2026년 10월 29일 · H.PLAN Windows 2.2, 모바일 웹앱 1.2 및 Android 1.0 기준

H.PLAN은 사용자의 일정과 할 일을 기기에 저장하는 플래너입니다. Google Drive·Calendar·할 일 연동과 알림은 사용자가 선택합니다.

1. 처리하는 정보와 목적

앱은 사용자가 입력한 일정, 할 일, 프로젝트 및 관련 기록을 저장하고 표시합니다. Drive를 연결하면 Google 계정 식별자와 이메일을 연결 계정 구분에 사용하며, 접근 토큰과 갱신 토큰을 Google API 인증에 사용합니다. 기기 식별자와 변경 이력은 여러 기기의 기록 병합 및 충돌 확인에 사용합니다.

2. 저장 위치와 Google로의 전송

기록은 사용자 기기에 저장됩니다. 연동을 켜면 동기화 대상 기록과 변경 정보가 Google API를 통해 해당 사용자의 Google Drive 내 H.PLAN 폴더에 저장됩니다. Calendar를 연결하면 선택한 캘린더의 일정 제목·설명·날짜·시간·반복 정보를 양방향으로 처리합니다. Google 할 일을 연결하면 제목·메모·날짜·완료 상태를 처리합니다. 웹 알림을 켜면 기기별 푸시 구독 정보와 알림에 필요한 일정 제목·예약 시각·연결 식별자를 Cloudflare 서버에 암호화해 저장합니다. 서버는 Google 일정의 수정·삭제를 확인해 예약 알림을 갱신하며, 완료된 예약은 정리합니다. 알림 서버에는 전체 업무 기록이나 메모 본문을 보관하지 않습니다. 이 서버는 Cloudflare Workers·D1에서 실행되며, 사용자가 동의한 Google 연결을 자동 갱신하기 위한 인증 정보와 계정 식별 정보를 처리합니다. 휴대전화 브라우저에서 Google API 직접 통신에 실패하는 경우, 연결된 같은 계정의 Calendar·할 일 요청과 응답을 기존 Cloudflare 연동 서버를 거쳐 전달할 수 있습니다. 이 대체 통신의 일정 본문은 별도 데이터베이스에 저장하거나 로그로 기록하지 않습니다. Google 로그인과 Drive·Calendar·할 일 서비스에는 Google의 개인정보처리방침이 적용됩니다.

3. 요청하는 Google 권한

openid 및 email은 계정을 식별하기 위해, drive.file은 앱이 생성했거나 사용자가 앱에 접근을 허용한 파일을 다루기 위해 사용합니다. Calendar 선택 목록에는 calendar.calendarlist.readonly, 일정 양방향 연동에는 calendar.events, Google 할 일에는 tasks 권한을 추가 동의로 요청합니다. 선택한 캘린더에만 적용하며, 권한을 허용하지 않아도 기존 기기 기록과 Drive 기능은 유지합니다. Google 비밀번호를 수집하거나 저장하지 않습니다. Google 사용자 데이터를 광고, 판매 또는 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

4. 보관과 삭제

로컬 기록과 Drive 파일은 사용자가 관리합니다. 자동 Drive 백업은 기기별 최근 30개를 유지하도록 구성되어 있으며, 한도를 넘으면 오래된 백업을 정리합니다. 앱에서 기록을 삭제해도 기존 백업에 기록이 남아 있을 수 있습니다. 완전히 제거하려면 관련 로컬 데이터 및 백업과 Drive 파일을 직접 삭제하고, 필요한 경우 Drive 휴지통도 비워 주세요.

5. 연결 해제와 권한 철회

앱 설정에서 연결을 해제하면 해당 기기의 연결 정보를 삭제하고 동기화를 중지합니다. 모바일에서는 서버에 보관한 해당 기기 연결과 알림 예약도 삭제합니다. 알림만 끄면 해당 기기의 구독·예약을 삭제합니다. 오프라인이라면 기기 연결부터 해제하고 서버 삭제 요청은 다음 온라인 실행 때 다시 처리합니다. 기존 로컬 기록과 Drive 파일은 자동으로 삭제하지 않습니다. Google 측의 앱 접근 권한은 Google 계정의 연결 관리에서 별도로 철회할 수 있습니다. 여러 기기를 사용한다면 각 기기의 연결과 데이터를 함께 확인해 주세요.

6. 보호 조치와 공유

PC 앱의 로그인 토큰은 Windows 암호화 저장 기능을 이용합니다. 모바일 웹앱은 기기에 무작위 기기 연결 키와 계정 표시 정보를 저장하고, Google 접근 토큰은 실행 중 메모리에만 보관합니다. 연결 유지 서버는 Google 갱신 권한과 계정 정보를 암호화하여 보관하고 접근 토큰을 자동 갱신합니다. 기기별 알림 예약은 발송·확인·해제 시 정리합니다. 180일간 사용하지 않은 서버 연결은 만료되며, 만료된 인증 기록은 이후 서버 정리 과정에서 삭제합니다. 사용자가 Google 권한을 철회하거나 기기 데이터를 삭제한 경우 다시 연결해야 합니다. Google과 HTTPS로 통신합니다. 동기화 파일 자체에 H.PLAN만의 종단간 암호화를 적용하지는 않습니다. Drive 공유 권한과 기기 접근 권한은 사용자 본인이 관리해야 합니다. 개발자는 사용자의 전체 개인 플래너를 수집하지 않습니다. 선택한 웹 알림의 최소 정보는 위에 설명한 암호화 예약 서버에서 처리합니다. Android 위젯과 기기 알림용 일정 캐시는 해당 휴대폰에 보관하며 앱 삭제 시 기기 정책에 따라 제거됩니다.

7. 홈페이지와 문의

자체 광고·분석 추적 코드를 두지 않습니다. 모바일 플래너 입력 양식의 기록은 브라우저 내부 데이터베이스에 먼저 저장됩니다. 임시 작성 내용은 해당 브라우저의 로컬 저장소에 보관할 수 있습니다. 사이트 데이터 삭제나 저장공간 정리로 기기 기록과 임시 기록이 사라질 수 있으므로 별도 백업을 권장합니다. 웹앱 실행 파일과 글꼴·아이콘은 오프라인 사용을 위해 기기에 캐시됩니다. 호스팅 제공자 GitHub는 서비스 운영 및 보안을 위해 접속 정보를 처리할 수 있습니다. 호스팅 및 인증 서버 제공자의 접속 정보 처리에는 GitHub 개인정보처리방침과 Cloudflare 개인정보처리방침이 적용됩니다.
